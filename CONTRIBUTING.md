# Contributing

Issues and pull requests are welcome. Keep changes focused and include tests for behavior changes.

- Run `swift test` and `bash ./scripts/build-and-test.sh` on an Intel Mac with Xcode.
- Preserve host-key verification, loopback-only VNC forwarding, and SSH/Viewer process ownership safety.
- Do not commit SSH keys, real connection profiles, credentials or machine-specific logs.
- Clearly document any third-party code or assets and their licenses.
- Contributions must be licensed compatibly with `GPL-2.0-or-later` and must not incorporate code that is restricted to `GPL-3.0-only` unless licensing is reviewed.
